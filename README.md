# Student Scholarship Portal

A web application developed to manage and apply for student scholarships.

## Features
- Student registration and login
- Scholarship application submission
- Admin approval system
- View scholarship status

## Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

## Installation

1. Clone the repository
git clone https://github.com/likhithar01/student_scholarship_portal.git

2. Navigate to the project folder
cd student_scholarship_portal

3. Create virtual environment
python -m venv venv

4. Activate virtual environment
venv\Scripts\activate

5. Install dependencies
pip install -r requirements.txt

6. Run the server
python manage.py runserver

Then open:
 https://studentscholarship.pythonanywhere.com
